F-NFP Extension — Privacy Policy

Last updated: August 6, 2026

F-NFP ("the extension") is an internal tool used by Breeze Airways flight dispatchers. It runs only on the Breeze N-Flight Planning (NFP) web application and adds operational planning information — fuel, alternate airport, and captain/dispatcher match — directly onto the NFP flight-list screen by retrieving it from the NFP webservice. This policy explains what information the extension handles and how.

In short: The extension does not sell, share, or transmit your data to any third party. The only data it handles are your NFP login credentials (kept in memory for your browser session) and flight planning data, and it communicates exclusively with the Breeze NFP host over HTTPS.

1. Information the extension handles

DataHow it is handled
NFP login credentials (airline code, username, password) Captured from the NFP login form when you sign in (or entered once via an in-app prompt). Held in memory only (chrome.storage.session) and used solely to authenticate requests to the NFP webservice. Sent only to the Breeze NFP host over HTTPS. Never written to disk, never sent to any third party, and automatically cleared when the browser is closed.
Flight planning data (flight numbers, routes, fuel, alternates, scheduled times, crew names shown on the operational flight plan) Read from the NFP flight list and the NFP webservice, then displayed on the flight-list screen. Processed locally within the browser/extension. Not transmitted anywhere other than back to the Breeze NFP host that provides it.

2. How the information is used

The information is used for a single purpose: to authenticate to the NFP webservice and display fuel, alternate, and crew-match information on the Breeze NFP flight-list screen. It is not used for any other purpose.

3. Data sharing and transfer

  • The extension does not sell or rent any data.
  • The extension does not transfer data to any third party.
  • The extension does not use any analytics, advertising, or tracking services.
  • All network communication is exclusively with the Breeze NFP host (mxy.nfp.vmc.navblue.cloud) over HTTPS — the same system the user is already logged in to.

4. Data storage and retention

Login credentials are stored only in chrome.storage.session, which keeps them in memory for the duration of the browser session and erases them when the browser is closed. The extension does not operate any server and does not retain your data anywhere after the browser session ends.

5. Permissions

PermissionWhy it is needed
storage To hold NFP credentials in memory for the browser session (chrome.storage.session) so webservice requests can be authenticated. Cleared on browser close.
Host access to mxy.nfp.vmc.navblue.cloud The extension runs on, reads from, and communicates only with the Breeze NFP host. It has no access to any other website.

6. Remote code

The extension contains no remotely hosted code. All logic is included in the published extension package and is not fetched or executed from any external source.

7. Security

All communication with the NFP host occurs over HTTPS. Credentials are held only in volatile session memory and are never written to persistent storage.

8. Children's privacy

The extension is an internal workplace tool and is not directed to, or intended for use by, children.

9. Changes to this policy

This policy may be updated from time to time. Material changes will be reflected by updating the "Last updated" date above.
